# Seeker Code — Private Code Editor with Seeker Pro 1.2

Seeker Code is a fast, private code editor that runs in your browser. Open any folder on your computer and edit with help from Seeker Pro 1.2, Seeker Perplex, and Seeker Code Flash.

## Getting started

```bash
npm install
npm run dev
```

## API Key

Settings only needs one field: your NVIDIA API key. The default key is pre-filled and used for all three Seekers:

- Seeker Pro 1.2 (architect)
- Seeker Perplex (deep builder)
- Seeker Code Flash (quick editor)

Change it in Settings → API Key. Your key stays only in your browser.
